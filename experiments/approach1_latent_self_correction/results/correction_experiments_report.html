Approach 1: correction experiments

All experiments use frozen Qwen3-VL-2B and the exported mixture-trained unified correctness head. Each study contains 100 examples, balanced across ChartQA, TextVQA, DocVQA, and ScienceQA. Accuracy is the dataset-specific metric converted to the binary correctness definition used to train the head.

Main result. Sampling five candidates and selecting with the unified head reaches 81.0%, compared with 78.0% for greedy generation. The five-candidate oracle is 85.0%.

Interpretation

A single prompted retry is unstable: it fixes some errors but can overturn correct answers. Scoring the retry limits that damage but provides only a small gain. Best-of-five generation is more promising because it separates candidate creation from candidate selection. The learned head outperforms majority voting and token likelihood, although the 85% oracle shows that candidate selection and candidate diversity both still leave room for improvement.
