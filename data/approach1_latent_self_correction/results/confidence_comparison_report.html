Confidence Estimation on ChartQA

Qwen3-VL-2B · 2,500 test questions · baseline accuracy 75.84%

Result: learned Q-heads identify unreliable answers much better than geometric-mean token confidence. After a 72-fit sweep, a linear pre-generation probe ranked errors best; the answer-conditioned verifier remains the appropriate head for judging a specific generated answer.

Approaches

1. Geometric-mean token confidence

Average the generated tokens' log probabilities, then exponentiate. This uses the model's own next-token certainty and requires no training.

Problem: 1,921 of 2,500 scores were exactly 1.0, even though many answers were wrong.

2. Learned Q-heads

Train small neural heads on frozen VLM representations with correctness labels.

Pre-generation: predicts whether the question will be answered correctly before seeing the answer.

Verifier: judges the specific generated answer and also learns to rank reference answers above incorrect candidates.

How the Q-heads were trained

We ran Qwen3-VL-2B once and saved frozen representations for the ChartQA train, validation, and test splits. Only the small correctness heads were trained; the VLM itself was not updated.

Head and optimization

The initial heads used a two-layer MLP: layer normalization, a 512-unit linear layer, GELU, 10% dropout, and a one-value output. The later sweep also tested a linear probe and an MLP with 256 hidden units.

AdamW · learning rate 0.001 · weight decay 0.0001 · batch size 512 · 20 epochs

Training objective

Both heads use binary cross-entropy plus a ranking loss that pushes correct examples above incorrect ones. For incorrect candidates, the verifier receives an additional paired-ranking objective that pushes the reference answer above the generated answer.

Loss and contrastive ranking

LBCE = −[y log σ(s) + (1−y) log(1−σ(s))]

Lrank = meani∈correct, j∈wrong softplus[−(si−sj)]

Lpair = meanj∈wrong softplus[−(sreference,j−scandidate,j)]

Lpre = LBCE + 0.25Lrank
Lverifier = LBCE + 0.25Lrank + 0.25Lpair

The batchwise term contrasts every correct example with every incorrect example in the batch. The paired term contrasts an incorrect generated answer with the reference answer for the same image and question.

How the paired contrast is constructed

For each training example, Qwen3-VL receives two completed conversations in separate teacher-forced forward passes:

[image, question, generated answer] → hcandidate → Q(hcandidate) = scandidate
[image, question, correct reference answer] → hreference → Q(hreference) = sreference

The image and question remain identical; only the assistant answer changes. We take the final layer's hidden state at the last answer token and pass both states through the same verifier head. When the generated answer is wrong, Lpair trains the verifier to score the correct reference higher.

The reference answer is training supervision only. At deployment, the verifier sees the image, question, and generated candidate—never the unknown correct answer.

The validation split selects a scalar temperature for probability calibration. The test split is used only for the final metrics shown below.

Small architecture and hyperparameter sweep

Using the cached frozen features, we trained 36 configurations for each approach (72 fits total):

architecture ∈ {linear, MLP-256, MLP-512}
learning rate ∈ {3×10−4, 10−3}
ranking weight ∈ {0, 0.25}
seed ∈ {1, 2, 3}

Configurations were selected by validation error AUPRC, with validation AUROC as the tie-breaker. The test set was then used for final evaluation.

Winning pre-generation head

Linear · LR 3×10−4 · ranking weight 0 · seed 3

A linear probe learns only s = wTh + b over the frozen prompt representation. It has no hidden layer, activation, normalization, or dropout.

This result suggests expected question difficulty is already close to linearly separable in the frozen representation.

Winning candidate verifier

Initial sweep: MLP-512 · LR 10−3 · ranking weight 0 · seed 1

The verifier sees the generated answer and can judge that particular candidate. It is the relevant head for deciding whether self-correction should run.

Across the sweep, plain BCE beat the contrastive objective: a ranking weight of 0 was selected for both winners.

Metric guide

AUROC
How often a correct answer is ranked above an incorrect one.
Error AUPRC
How well errors are concentrated at the top of the review or correction queue.
Brier score
Squared error between predicted correctness probability and the actual outcome.
ECE
Gap between stated confidence and observed accuracy; lower means better calibration.
Coverage accuracy
Accuracy after keeping only the most confident fraction of answers.
ECE correction: the original metric code excluded confidence values equal to 1.0 from its final bin. The chart uses the corrected geometric-confidence ECE of 0.172. The sweep also used the corrected implementation.

Takeaway

The sweeps substantially improved both learned baselines. The linear pre-generation probe has the highest AUROC, but it predicts expected difficulty rather than checking an answer. The early-stopped verifier with weak contrastive weight 0.01 has the highest error AUPRC and is the relevant model for self-correction decisions. Its advantage over BCE-only is small and should be validated out of distribution.

Next steps

Improve verifier representations

Compare features from several transformer layers and pooling choices. Explicitly test the answer-induced change:

hprompt,   hcandidate,   hcandidate − hprompt

Use harder negatives

Train with multiple plausible wrong answers per question: sampled generations, nearby chart values, numerically close answers, and formatting variants.

Measure seed stability

Select hyperparameters using mean validation performance across seeds, then report the final mean and standard deviation over three independently trained models.

Test the correction policy

Trigger correction for the riskiest 10–30% of candidates. Measure errors fixed, correct answers damaged, net accuracy gain, coverage, and added inference cost.

Evaluate distribution transfer

Train on ChartQA and evaluate on another chart or visual-reasoning dataset to determine whether the heads learn general correctness signals or ChartQA-specific shortcuts.

Possible improvement: weak contrastive regularization

A follow-up verifier sweep found that a small ranking weight of 0.01 narrowly beat BCE-only on mean validation error AUPRC and reduced variation across seeds. Larger weights degraded steadily.

Lverifier = LBCE + 0.01Lrank + 0.01Lpair

The weak paired constraint may improve generalization by encouraging the transferable relation scorrect reference > sincorrect candidate without overpowering the correctness objective. This remains a hypothesis: freeze the weight-0 and weight-0.01 models and compare them on an unseen dataset or shifted ChartQA subset.

Recommended first experiment: layer and pooling selection with hcandidate − hprompt. It directly targets answer verification without fine-tuning the VLM.
