# Candidate search: temperature, pool size and selector

Pool k is the greedy answer plus the first k samples at the given temperature (top-p 0.95). Mixed pools are questions whose pool holds both a right and a wrong answer; selection can only matter there. Headroom captured is (selector − greedy) / (oracle − greedy). Grouped AUROC ranks right against wrong answers within one question. The configuration is chosen on validation; test is read once for it.
